Governing definitions

From irrs-kernel/src/lib.rs (frozen): "A directed relation declared from observable information." Three foundational characteristics:

  • Complexity — multiple observables; no isolated singleton
  • Change as the only observable constant — relations evolve; no fixed state

Declared-information rule (§1): not-evaluated ≠ evaluated with result 0.0. An operator not evaluated for lack of declared prerequisites leaves its output slot empty, not zero.

2.4 Physical feedback cycle vs. mathematical circulation

The robotics demo implements a physical sensor–actuator feedback cycle:

Physical cycle (spans step boundaries) τs(t) → A → B → Σ → C → vcmd(t) → plant → τs(t+1)

This cycle is real and produces the next observation. However, it crosses step boundaries: τs(t+1) is produced by the plant and admitted through M at the next step. It is not part of D at step t.

STRUCTURAL FINDING — SF-1 (new, this revision)

Within a single step t, the topology is an acyclic DAG (vτ₀ ← vτ₁ → vΔI → vΔV). No mathematical cycle exists within D at a single time step. The R operator's antisymmetric circulation χ[e] is defined over edge cycles in the topology. This definition has no natural instantiation on a two-edge acyclic path.

The physical feedback cycle does not automatically establish the mathematical circulation required by R. They are distinct. Closing the cycle would require declaring a cross-step edge (vΔV(t) → vτ₁(t+1)) and a multi-step topology. This is returned to Origin as OC-M0R-5.

INTERIOR LOCUS — SATISFIED

Locus vΔI is both the target of eτI and the source of eIV. The interior-locus condition (region.rs — at least one node that is both target of one edge and source of another) is satisfied for the coupling sub-topology.

Task 3 — Kernel V8 operator mapping

3.1 A operator — EVALUATED

Kernel V8 §10 — A operator (operators.rs line 26) A(x)[e] = x[src(e)] − x[tgt(e)] Applied to epersist: A(x)[epersist] = x[vτ₁] − x[vτ₀] = τs(t) − τs(t−1) = Aout

Environmental quantities (MASS, ARM, G) do not enter A. The directed difference is the sole output; it is not the absolute torque reading.

3.2 B operator — EVALUATED

Kernel V8 §11.1 — B operator B(g)[e] = g[e] + Σf ∈ succ(e) g[f] where succ(e) = { f : src(f) = tgt(e) }

The edge field g over the coupling sub-topology is initialized from Aout via the declared coupling constants KT and RW:

Edge field g (coupling sub-topology) g[eτI] = Aout / KT = ΔI g[eIV] = ΔI × RW = ΔV succ(eτI) = { eIV } // tgt(eτI) = vΔI = src(eIV) succ(eIV) = { } // terminal edge B(g)[eτI] = g[eτI] + g[eIV] = ΔI + ΔV B(g)[eIV] = g[eIV] = ΔV // no successors
FINDING — SF-2: B full tensor vs demo usage

The robotics demo uses ΔV = g[eIV] = B(g)[eIV] as the Sigma input. The full B tensor also produces B(g)[eτI] = ΔI + ΔV, which is not currently consumed. Both are valid B outputs over the declared topology. The choice of which B value feeds Sigma is a domain declaration, not a kernel decision. Returned to Origin for acknowledgment (OC-M0R-6).

3.3 R operator — NOT EVALUATED

Kernel V8 §11.2 — R operator R(g)[e] = g[e] + ρ[e] · (Σf ∈ adj+(e) g[f] − Σf ∈ adj−(e) g[f]) adj+(e) = { f : src(f) = tgt(e) } adj−(e) = { f : tgt(f) = src(e) } ρ[e] = f(ρbase, χ[e], χ₀) // RhoSaturatingForm — OPEN

The adjacency structure is present in the declared topology:

R structural prerequisites (present) adj+(eτI) = { eIV } // tgt(eτI) = vΔI = src(eIV) ✓ adj−(eτI) = { } // no edges end at src(eτI) in coupling sub-topology adj+(eIV) = { } // terminal adj−(eIV) = { eτI } // tgt(eτI) = vΔI = src(eIV) ✓
R formulas given topology (prerequisites unfilled) R(g)[eτI] = g[eτI] + ρ[eτI] · (g[eIV] − 0) = ΔI + ρ[eτI] · ΔV R(g)[eIV] = g[eIV] + ρ[eIV] · (0 − g[eτI]) = ΔV − ρ[eIV] · ΔI
